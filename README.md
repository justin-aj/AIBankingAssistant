# 🏦 AI Banking Assistant

A domain-specific AI assistant fine-tuned for banking queries and conversational financial assistance. This project leverages transformer-based large language models (LLMs) with Parameter-Efficient Fine-Tuning (PEFT) techniques for scalable, high-quality natural language generation.

---

## 📌 Project Overview

This project involves building a robust AI banking assistant using fine-tuned transformer models. It focuses on two core NLP tasks:
- **Question Answering**  
- **Conditional Text Generation**

Over **25,000 banking-related Q&A pairs** were used to train and evaluate the models. Dataset taken from Kaggle.

---

## 🧠 Models Fine-Tuned

| Model           | Size    | Tasks                    | Fine-Tuning Method |
|----------------|---------|--------------------------|--------------------|
| T5-small        | 60M     | QA + Generation          | QLoRA (PEFT)       |
| GPT2-small      | 110M    | Conditional Generation   | QLoRA (PEFT)       |
| DistilBERT      | 66M     | Question Answering       | QLoRA (PEFT)       |
| Falcon-7B       | 7B      | Generation (Final Phase) | Full + QLoRA       |

The best performances were observed only in Falcon-7B. I was just playing with the other models.

## ⚙️ Technologies Used

- **Transformers** – [Hugging Face Transformers](https://github.com/huggingface/transformers)
- **PEFT** – QLoRA for efficient low-rank adaptation
- **PyTorch** – Model training and evaluation
- **CUDA** – GPU acceleration using NVIDIA V100 (Used via Northeastern University Discovery GPU Clusters)
